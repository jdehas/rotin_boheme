# Rotin Bohème

Site témoin et direction artistique de Rotin Bohème (Bernadette Wilkin), réalisés par Balthazar Studio.

- `docs/` : le site témoin (HTML, CSS, JS), publié avec GitHub Pages. Pages : home, À propos (La troupe des objets retrouvés), fiches lampes.
- `direction-artistique/` : charte, logotypes, identités, univers, maquettes immersives et PDF du carnet de route.

Les photos des pièces viennent de Cloudinary.
